# id-gen
Welcome!
This little library for ID generation in C was made with the intension to showcase how I would implement ID generation in 64 bits, that would still be indexable.
## What's worth of learned from it
- How much information could be stuck inside 64 bits
- How remote servers could all create indexes and still have no clashes, as the indexes need to be unique.
- How CPU works with cache buffers on synchronization calls, and how other architectures than x86 synchronizes, and how it changed over time.
